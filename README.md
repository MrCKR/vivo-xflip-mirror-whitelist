# 魔镜白名单 · vivo X Flip

**让原本无法添加的 App，也能出现在 vivo X Flip 的原生「魔镜应用」里。**

不需要 Root，不用换外屏桌面。放行后，仍从手机自带的「魔镜应用」入口打开 App。

> **下载状态：**当前公开的是 **1.3.1 源码，尚未发布可直接安装的 APK**。[安装包发布页](https://github.com/MrCKR/vivo-xflip-mirror-whitelist/releases)目前没有安装包。「Code → Download ZIP」下载的是源码，**不能当作 App 安装**。下面的步骤适用于已获得安装包的用户。

## 我的手机能用吗？

目前仅在 **vivo X Flip（V2256A / PD2256）**、Android 16 / OriginOS 16、系统外屏启动器 4.0.0.1 上验证。其他机型或系统版本不保证可用，不能因为是折叠屏就认为一定支持。

它解决的是「允许添加」，**不是把所有 App 自动适配成外屏版**。部分应用可能出现显示不完整、文字太小、输入不方便或无法打开的问题。原生魔镜应用的 **32 个已添加上限仍然保留**。

## 第一次使用：安装与授权

建议在内屏操作，先选一个应用验证，不要一开始就用「全部加入」。

### 1. 安装应用

取得本项目的 APK 后，在手机上打开并按系统提示安装。再从 [Shizuku 官网](https://shizuku.rikka.app/zh-hans/)提供的渠道安装 Shizuku。

目前仓库未提供 APK 下载，请勿把未知来源的同名软件当成本项目。

### 2. 启动 Shizuku（本机即可，不必连接电脑）

1. 手机连接可信 Wi-Fi，开启开发者选项中的 **USB 调试**和 **无线调试**。
2. 打开 Shizuku，选择「通过无线调试启动」下的 **配对**。
3. 按提示进入系统「无线调试 → 使用配对码配对设备」，在 Shizuku 通知里输入配对码。
4. 配对成功后，回到 Shizuku 点击 **启动**，确认显示正在运行。

如果通知一直显示「搜索中」，保持系统配对码窗口打开，并允许 Shizuku 后台运行和联网。详细步骤见 [Shizuku 官方使用说明](https://shizuku.rikka.app/zh-hans/guide/setup/)。

### 3. 给魔镜白名单授权

打开魔镜白名单，点击顶部 **「Shizuku 未授权 · 点击连接」**，或在右上角更多菜单选择 **「Shizuku 授权 / 检查」**，在授权窗口中允许本应用。

授权后，顶部应显示 **「Shizuku 已连接」**。

### 4. 授予写入权限（只需一次）

**Shizuku 授权和白名单写入权限是两回事，两项都要完成。当前 App 不会自动授予写入权限。**

如果顶部仍显示 **「写入权限未授权」**，需要执行下面一条命令：

- **本机方式：**在已接入并获准使用 Shizuku 的终端中执行：

  ```sh
  pm grant com.openminis.mirrorwhitelist android.permission.WRITE_SECURE_SETTINGS
  ```

  必须在 **Shizuku shell 环境**中执行，普通终端直接粘贴不一定有效。Shizuku 本身不是输入命令的终端：请打开 Shizuku 中的 **「在终端应用中使用」**，按它的说明为你的终端配置 `rish`，进入后再执行上面的命令。如果不会配置，可使用下面的电脑 ADB 方式；当前 App 尚无一键完成此授权的功能。

- **有电脑时的替代方式：**连接并授权 ADB 后执行：

  ```sh
  adb shell pm grant com.openminis.mirrorwhitelist android.permission.WRITE_SECURE_SETTINGS
  ```

执行后回到 App，确认顶部同时显示 **「Shizuku 已连接」**和 **「安全设置权限已授权」**，再继续。卸载重装后需重新授予写入权限。

## 怎么把一个 App 加到外屏？

例如要添加 Minis：

1. 在魔镜白名单中搜索 **Minis**，打开它右侧的开关。
2. 保持 **「自动刷新外屏」**开启，等待出现 **「原生外屏已同步」**。刷新时外屏桌面可能短暂重载。
3. 点击顶部卡片里的 **「魔镜管理」**按钮。
4. 在 vivo 原生页面的 **「可添加」**区域找到 Minis，点一下，把它放进 **「已添加」**区域。
5. 折叠手机，点亮并解锁外屏，进入 **「魔镜应用」**，点击 Minis 图标。

**打开白名单开关只是允许添加，不等于已经添加到外屏。第 3、4 步不能省略。**

修改后只会自动刷新，**不会自动跳转管理页**，需要时由你点击「魔镜管理」。

如果外屏桌面没有「魔镜应用」图标，请在系统 **「外屏专区 → 外屏应用 → 外屏桌面管理」**中添加它；也可按原生管理页中的「前往添加」提示操作。菜单名称可能随系统版本变化。

## 日常操作

- **找应用：**搜索名称或包名，或切换「全部应用 / 已放行 / 未放行」。
- **排序：**已放行在前，同状态按名称排列，没有特殊 App 置顶。
- **重新同步：**点击「重新刷新」，成功后再进「魔镜管理」。
- **移除外屏应用：**先在原生魔镜管理页移除，再关闭白名单开关。只关开关不保证移除已有图标。
- **全部加入：**位于右上角更多菜单，只扩大可添加范围，不会自动把所有 App 放进外屏，也不突破 32 个上限。建议按需放行。

## 常见问题

| 遇到的问题 | 怎么处理 |
|---|---|
| 开关开了，外屏没有这个 App | 检查是否还没在「魔镜管理 → 可添加」里点选添加。 |
| 原生「可添加」区域也没有 | 回到本 App 点击「重新刷新」，成功后再进管理页。不要清除外屏启动器数据，以免丢失布局。 |
| Shizuku 未连接 / 未授权 | 先确认 Shizuku 正在运行，再给本应用授权。手机重启后通常需重新启动 Shizuku。 |
| 写入权限未授权 | 完成上面的第 4 步；Shizuku 已连接不代表写入权限已授予。 |
| 刷新失败或一直等待 | 确认 Shizuku 正常，重试刷新；必要时点亮并解锁外屏后再试。不要反复清除系统组件数据。 |
| 打开后显示不正常 | 白名单不负责修改目标 App 的界面，小外屏布局、输入法和安全限制仍取决于应用及系统。 |

### 更新、重启或卸载后会怎样？

手机重启后通常需要重新启动 Shizuku；系统更新可能改变外屏规则。白名单和原生已添加列表在重启后的长期保持、OTA 兼容性尚未全面验证。

**卸载本 App 不等于撤销已做的修改。**如果要移除已添加应用，请先在原生魔镜管理页移除，再关闭对应白名单开关。本 App 没有备份或一键还原功能。
